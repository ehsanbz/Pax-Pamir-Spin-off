# Pax-Pamir-Spin-off

A Persian-language historical atlas exploring the people, places, events, and relationships behind **Pax Pamir: Second Edition**.

**[Open the atlas](https://ehsanbz.github.io/Pax-Pamir-Spin-off/)** · **[Read the research report](https://ehsanbz.github.io/Pax-Pamir-Spin-off/research.html)**

## Explore

- Research profiles for all 116 cards: 41 historical people, one fictional character, 58 thematic cards, 12 event cards, and four structural cards.
- An interactive chronology containing 39 dated historical events.
- A geographic map and a network of 97 sourced relationship records.
- Clickable biographies, citations, search, filters, and a printable research report.

The interface and research are in Persian. Dates are Gregorian. Selected activity periods are not complete lifespans. The map uses contemporary boundaries for orientation, not reconstructed historical borders. Uncertain claims and thematic interpretations are identified in the profiles.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Self-contained interactive atlas, including card images and map data |
| `research.html` | Standalone research text for reading and printing |
| `research-data.json` | Structured research records without embedded card images |
| `preview.jpg` | Preview of the atlas |
| `.nojekyll` | Serve the static site directly through GitHub Pages |

No installation or build is required. Open `index.html` in a modern browser, or use the published GitHub Pages site. The atlas content and visualizations are self-contained; external source links require an internet connection.
